# 股票资讯AI智能分析系统

> 面向A股市场的资讯聚合与智能分析系统：7×24 市场快讯、概念风口追踪、多因子趋势评分、业绩数据全景，并为每只个股提供大模型驱动的智能分析。
> 技术栈：**FastAPI + Vue3 + Element Plus + ECharts**，数据来自东方财富/腾讯公开接口
> 定位：学习研究用演示项目，不构成任何投资建议

## 功能模块

| 模块 | 说明 | 实现方式 |
|---|---|---|
| 市场概览 | 上证/深证/创业板/恒指等指数实时行情 | 东财指数接口，分钟级刷新 |
| 市场资讯 | 7×24 财经快讯流，含要闻标记与原文跳转 | 东财 7×24 快讯接口 |
| 长线风口龙头 | 概念板块涨幅榜 + 每个风口的领涨股 | 东财概念板块接口，按涨幅取 Top8 |
| 机构调研推荐热门股 | 关键词 + 等级 + 评分的热门股榜单 | 自研三因子评分：板块热度(40)+个股动量(20)+换手活跃度(30) |
| 业绩预测 | 报告期切换（中报/一季报/年报），营收/净利润同比排序，行业筛选 | 东财业绩报表接口 |
| 趋势股评分 | 60日动量35% + 主力资金25% + 量比20% + 换手活跃度20%，分位数归一 | 样本为60日涨幅Top200，输出Top50评分榜 |
| 搜索股票 | 代码/名称模糊搜索 | 全A代码表本地缓存（5558只，1小时TTL）+ 过滤 |
| 个股详情 | 实时报价 + 日K蜡烛图/成交量 | 腾讯行情源 + ECharts |
| AI 智能分析 | 四段式个股分析（技术面/量价资金/消息面/风险提示） | LLM（Anthropic/OpenAI 兼容协议），规则版兜底 |

## 快速启动

```bash
# 后端
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --port 8000

# 前端
cd frontend
npm install
npm run dev   # http://localhost:5173
```

LLM 分析：在 `backend/.env` 中配置 `ANTHROPIC_BASE_URL` / `ANTHROPIC_AUTH_TOKEN` / `ANTHROPIC_MODEL`
（或 `OPENAI_BASE_URL` / `OPENAI_API_KEY` / `OPENAI_MODEL`）；未配置时自动回退到规则版分析，保证零成本可用。

## 工程决策

1. **双数据源容灾**：东财 push2 主机偶发限流断连，个股行情/K线采用腾讯源为主、东财为备，接口层 4 次指数退避重试
2. **搜索去第三方依赖**：东财 suggest 接口返回不稳定（JSONP/字段漂移），改为一次性分页缓存全 A 股代码表本地过滤
3. **评分模型可解释**：趋势评分的因子构成与权重全部显式声明，分位数归一消除极端值影响，输出可复现、可验证
4. **LLM 成本控制**：AI 分析按需调用，规则版兜底保证零 Key 可用；thinking 块过滤只保留正文
